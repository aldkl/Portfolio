01

추상화와 다형성

추상 클래스로 공통 상호작용 규칙을 분리하고, 기능별 클래스가 상속과 오버라이드로 동작을 확장하도록 구성할 수 있습니다.

싱글턴과 매니저 구조

게임 상태와 공용 데이터를 관리하는 싱글턴 매니저를 구성하고, 씬이 바뀌어도 필요한 상태를 유지할 수 있습니다.

03

상태 기반 게임 로직

열거형과 상태 이름 규칙을 사용해 캐릭터 애니메이션, 월드 표현과 플레이 조건이 함께 전환되는 로직을 구현할 수 있습니다.

04

데이터 기반 콘텐츠

Recipe와 Ingredient 같은 데이터를 리스트로 관리하고, HashSet과 LINQ를 활용해 조합과 조건을 판정하는 시스템을 만들 수 있습니다.

05

Unity 게임플레이 시스템

이동, 상호작용, 퍼즐, 충돌, 저장과 불러오기, 비동기 씬 전환 등 플레이 흐름에 필요한 기능을 연결할 수 있습니다.

06

이벤트와 비동기 처리

이벤트 콜백과 코루틴을 사용해 영상 종료, UI 연출, 시간 지연, 오브젝트 생성과 로딩 흐름을 제어할 수 있습니다.

07

SRP Batcher와 Static Batching을 적용하고, 라이트맵 UV와 그림자 옵션을 조정해 드로우콜과 실시간 렌더링 비용을 줄이는 작업을 할 수 있습니다.

08

실시간 셰이더와 Technical Art

URP 툰 라이팅, SDF 얼굴 그림자, Rim Light, 거리 기반 디더링과 월드 좌표 UV 등 프로젝트에 필요한 화면 표현을 구현할 수 있습니다.
